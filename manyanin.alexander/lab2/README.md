# Лабораторная работа 2

## Задание

Вариант 21. Функция `generatePrimes(n)` возвращает массив простых чисел, не
превышающих `n`, по возрастанию.

## Реализация

Использовно решето Эратосфена. Сначала все числа от 0 до `n` считаются простыми,
затем для каждого `i` с условием `i * i <= n` вычёркиваются его кратные, начиная
с `i * i`. Оставшиеся числа начиная с 2 попадают в результат. Для `n < 2`
возвращается пустой массив.

## Запуск

Импортируйте именованный export из `solution.js` как ES module:
`import {generatePrimes} from './solution.js';`.
