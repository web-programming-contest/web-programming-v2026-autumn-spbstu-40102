# Лабораторная работа 1

## Задание

Вариант 21. Адаптивное меню: на широком экране пункты идут в строку, а на узком
(меньше 768 пикселей) выстраиваются в один столбец.

## Реализация

Меню сделано списком ссылок внутри `nav`. Список раскладывается через flexbox
(`display: flex`). Медиазапрос `@media (width <= 767px)` меняет направление на
`flex-direction: column`. Стили лежат в `styles.css`.

## Запуск

открыть `index.html` в браузере и менять ширину окна.
