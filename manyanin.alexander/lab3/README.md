# Лабораторная работа 3

## Задание

Вариант 21. Функция `findMaxSubarraySum(arr, n)` возвращает максимальную сумму
`n` подряд идущих элементов массива `arr`, где `1 <= n <= arr.length`.

## Реализация

Применён метод скользящего окна. Сумма первого окна считается напрямую, а дальше
при сдвиге на один элемент к сумме прбавляется новый элемент и вычитается
вышедший. Максимум начинается с суммы первого окна, поэтому функция нормально
работает и с числами <0. Массив не изменяется

## Запуск

Импортируйте именованный export из `solution.js` как ES module:
`import {findMaxSubarraySum} from './solution.js';`.
