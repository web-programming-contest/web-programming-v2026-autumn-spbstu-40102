# Лабораторная работа 4

## Задание

Создать класс `Movie` с полями `title`, `director`, `actors` и методами
`addActor`, `removeActor`, геттером `castSize`. Реализовать функции работы с
коллекцией фильмов: группировка по режиссёру, получение уникальных актёров,
группировка по количеству актёров, поиск фильмов по актёру, получение всех
названий. Реализовать пользовательский интерфейс с карточками фильмов, формами
добавления/удаления фильма и актёров, асинхронными операциями через
`Promise + setTimeout` и сохранением в `localStorage`.

## Реализация

Решение разделено на модель (`model.js`) и интерфейс (`main.js`). Класс `Movie`
инкапсулирует данные о фильме. Функции коллекции используют `reduce`, `flatMap`,
`filter`, `map` и не мутируют входной массив. UI рендерится динамически через
функцию `render`. Состояние сохраняется в `localStorage` при каждом изменении и
восстанавливается при загрузке страницы. Все операции добавления/удаления
(фильмов и актёров) обёрнуты в `Promise + setTimeout` для асинхронности.

## Запуск

Открыть файл `index.html` в браузере. Данные сохраняются в `localStorage` и
восстанавливаются после перезагрузки страницы.
