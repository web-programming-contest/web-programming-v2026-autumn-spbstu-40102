# Лабораторная работа 3

## Задание
Реализуйте функцию findMostFrequent(arr), которая возвращает самый
часто встречающийся элемент в массиве.

## Реализация
Функция использует объект `counts` для подсчёта частоты каждого элемента за один проход по массиву. Ключи приводятся к строке через `String(item)` для корректного подсчёта. Функция возвращает элемент с максимальным количеством повторений. Входной массив не изменяется.

## Запуск
Импортируйте именованный export из `solution.js` как ES module.
