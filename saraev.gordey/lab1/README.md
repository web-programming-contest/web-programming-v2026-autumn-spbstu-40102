# Лабораторная работа 1

## Задание

Создать базовый макет веб-страницы, содержащий заголовок, боковую панель,
основную часть с контентом и футер. Для верстки макета необходимо использовать
Flexbox или Grid. Боковая панель должна иметь фиксированную ширину 300px, а
основной контент должен занимать все оставшееся свободное пространство. Каждый
элемент макет должен иметь цвет фона, отличающийся от других элементов, и черную
рамку, ширина которой состаляет 1px.

## Реализация

Использован Flexbox (`display: flex`). Для `body` задано
`flex-direction: column` и `min-height: 100vh` для растягивания на всю высоту
окна. Боковая панель имеет фиксированную ширину `300px` и `flex-shrink: 0`,
чтобы не сжиматься. Основной контент занимает всё оставшееся пространство
благодаря `flex: 1`.

## Запуск

Открыть файл `index.html` в любом браузере.
