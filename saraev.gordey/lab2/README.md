# Лабораторная работа 2

## Задание

Написать функцию calculateExpression(expr), вычисляющую значение математического
выражения в строке (например, "2 + 3 * 4" → 14).

## Реализация

Функция принимает строку с математическим выражением, проверяет корректность
входных данных (тип, допустимые символы). Вычисление производится через
безопасный конструктор `new Function`. Обрабатываются граничные случаи: пустая
строка, нечисловой результат, недопустимые символы.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
