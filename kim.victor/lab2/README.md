# Лабораторная работа 2

## Задание

Вариант 35. Реализовать функцию `findMissingNumber`, которая находит пропущенное
число в последовательности.

## Реализация

Функция `findMissingNumber` экспортируется из `solution.js` как именованный ES
module export и использует формулу суммы арифметической прогрессии для поиска
пропущенного элемента.

## Запуск

Импортируйте именованный export `findMissingNumber` из файла `solution.js` как
ES module.
