# Лабораторная работа 3

## Задание

Вариант 35. Реализовать функцию `findMedian`, которая находит медиану массива
чисел.

## Реализация

Функция `findMedian` экспортируется из `solution.js` как именованный ES module
export.

Для расчета создается копия исходного массива, сортируется по возрастанию, после
чего возвращается центральный элемент (для нечетного количества элементов) или
среднее арифметическое двух центральных элементов (для четного).

## Запуск

Импортируйте именованный export `findMedian` из файла `solution.js` как ES
module.
