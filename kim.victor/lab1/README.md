# Лабораторная работа 1

## Задание

Разработать HTML-страницу с постраничной навигацией.

Вариант: 35.

## Реализация

На странице реализована постраничная навигация с кнопками перехода между страницами.

Используются HTML и CSS.

Для активной страницы используется отдельное оформление.
При наведении курсора на элементы навигации изменяется цвет фона.

## Запуск

Открыть файл `index.html` в браузере.
