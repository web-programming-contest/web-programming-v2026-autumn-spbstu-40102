# Лабораторная работа 4

## Задание

Вариант 35 (задача `blog-post`): разработать модель блог-публикации и интерфейс
для управления публикациями, тегами и комментариями.

Модель должна экспортировать класс `BlogPost` и функции `groupPostsByTag`,
`getUniqueTags`, `groupPostsByCommentCount`, `findPostsByTag`,
`getCommentAuthors`.

## Реализация

- `model.js` содержит класс `BlogPost`, начальные данные и пять функций для
  работы с коллекцией.
- `main.js` отвечает за добавление и удаление публикаций, отображение карточек и
  сохранение состояния.
- `index.html` содержит форму и список публикаций.
- `styles.css` задаёт адаптивное оформление страницы.

Добавление и удаление выполняются асинхронно через `setTimeout`. Список
сохраняется в `localStorage` и восстанавливается после перезагрузки страницы.

## Запуск

Откройте папку `lab4` в VS Code и запустите `index.html` через Live Server.
Также можно открыть `index.html` в браузере напрямую: внешние зависимости не
используются.
