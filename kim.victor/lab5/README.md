# Лабораторная работа 5

## Задание

Вариант 35 — «Финансовый отчёт». Необходимо разработать интерактивное
React-приложение для учёта доходов и расходов. Пользователь должен иметь
возможность добавлять финансовые операции, просматривать историю и видеть
диаграмму соотношения доходов и расходов.

## Реализация

Приложение реализовано на React с использованием Vite. Основной компонент
`FinanceApp` хранит список операций, описание, сумму, тип операции и выбранный
фильтр в состоянии React.

Реализованы:

- добавление доходов и расходов с проверкой описания и положительной суммы;
- отображение текущего баланса, общей суммы доходов и расходов;
- история операций с датой, суммой и типом;
- фильтрация истории по всем операциям, доходам и расходам;
- удаление отдельной операции;
- столбчатая диаграмма доходов и расходов;
- автоматическое сохранение данных в `localStorage` и восстановление после
  перезагрузки.

Для элементов, используемых автоматической проверкой, добавлены публичные
атрибуты `data-testid`: `app`, `transaction-description`, `transaction-amount`,
`transaction-type`, `transaction-add`, `transaction-history`,
`transaction-item`, `finance-chart`.

## Запуск

Требуется Node.js 24.19.0 или совместимая актуальная версия и npm.

```bash
cd lab5
npm install
npm run dev
```

Откройте адрес, который Vite выведет в терминале (обычно
`http://localhost:5173`). Для проверки production-сборки выполните:

```bash
npm run build
```
