# Лабораторная работа 3

## Задание

Реализовать функцию `findEquilibriumIndex(arr)`, которая находит индекс, где
сумма элементов слева равна сумме элементов справа.

## Реализация

Функция реализована на JavaScript в файле `solution.js` и экспортируется как
именованный экспорт. Сначала считается сумма всех элементов, затем массив
проходится один раз с накоплением суммы слева. Сам элемент с найденным индексом
в суммы не входит. Возвращается первый подходящий индекс, а если такого индекса
нет, то `-1`.

## Запуск

Подключить функцию командой
`import { findEquilibriumIndex } from "./solution.js";` и вызвать её с массивом
чисел в качестве аргумента. Страница `index.html` подключает `solution.js` как
модуль.
