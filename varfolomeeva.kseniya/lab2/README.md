# Лабораторная работа 2

## Задание

Написать функцию `findLongestPalindrome(str)`, которая находит и возвращает
самую длинную подстроку-палиндром в переданной строке.

## Реализация

Функция реализована на JavaScript в файле `solution.js`. Страница `index.html`
подключает этот файл, результаты проверки функции выводятся в консоль браузера.

## Запуск

Открыть файл `index.html` в браузере и открыть консоль разработчика (F12).
