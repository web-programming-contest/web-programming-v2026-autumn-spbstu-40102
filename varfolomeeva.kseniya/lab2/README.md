# Лабораторная работа 2

## Задание

Написать функцию `findLongestPalindrome(str)`, которая находит и возвращает
самую длинную подстроку-палиндром в переданной строке.

## Реализация

Функция реализована на JavaScript в файле `solution.js` и экспортируется как
именованный экспорт. Для поиска используется расширение палиндрома от центра.

## Запуск

Подключить функцию командой
`import { findLongestPalindrome } from "./solution.js";` и вызвать её со строкой
в качестве аргумента. Страница `index.html` подключает `solution.js` как модуль.
