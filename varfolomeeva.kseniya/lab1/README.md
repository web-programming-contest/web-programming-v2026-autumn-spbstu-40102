# Лабораторная работа 1

## Задание

Создать веб-страницу с изображением флага Бангладеш. Красный круг должен
располагаться по центру зелёного прямоугольника и сохранять своё положение при
изменении размеров флага.

## Реализация

Страница реализована с использованием HTML и CSS.

Для флага задано соотношение сторон 5:3. Для круга используется абсолютное
позиционирование относительно флага: контейнеру задано `position: relative`, а
кругу — `position: absolute`.

Центрирование выполнено с помощью `top: 50%`, `left: 50%` и
`transform: translate(-50%, -50%)`. Размер круга зависит от высоты флага.

## Запуск

Открыть файл `index.html` в браузере. Стили подключаются из файла `styles.css`.
