# Лабораторная работа 2

## Задание

Вариант 17 - создать аббревиатуру из первых букв слов. Лишние пробелы не
учитываются, результат возвращается в верхнем регистре

## Реализация

Функция `toAbbreviation` находит слова, берёт их первые буквы и переводит
результат в верхний регистр

## Запуск

Импортируйте `toAbbreviation` из `solution.js` как именованный ES export
