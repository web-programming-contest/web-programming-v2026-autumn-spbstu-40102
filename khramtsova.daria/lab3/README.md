# Лабораторная работа 3

## Задание

Вариант 17 - найти максимум каждого непрерывного окна длины `k` в массиве чисел

## Реализация

Функция `maxSlidingWindow` хранит индексы нужных элементов в очереди. Алгоритм
работает за линейное время и не изменяет исходный массив

## Запуск

Импортируйте `maxSlidingWindow` из `solution.js` как именованный ES export
