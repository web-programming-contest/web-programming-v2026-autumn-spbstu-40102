# Лабораторная работа 1

## Задание

**Вариант №7**. Создать три карточки товара. Каждая карточка должна быть
представлена div-блоком, содержащим:

- Изображение (размер 200px на 150px);
- Заголовок (шрифт Arial, размер 18px, жирный стиль);
- Описание (шрифт Arial, размер 14px). Карточки должны располагаться в одну
  строку (горизонтально) с отступом 20px между ними. Для всех элементов
  используйте padding: 10px.

## Реализация

### Разметка

Основной контейнер с карточками `container-cards`. Карточка - `div` блок класса
`card` с изображение и `div` блоком класса `card-content` в корором размещены
загаловок и текст карточки

### Стили

- `padding` применён ко всем объектам, т.е.: `card`, `image-card`, `card-title`,
  `card-text`
- шрифт наследуемый атрибут поэтому передан в класс `card`
- остальные атрибуты выбраны с учётом тз

## Запуск

Откройте `index.html` в браузере.
