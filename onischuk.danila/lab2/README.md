# Лабораторная работа 2

## Задание

Вариант 7. Написать функцию findLongestPalindrome(str), которая находит и
возвращает самую длинную подстроку-палиндром в переданной строке.

## Реализация

Расширение от центра. Перебираем каждую позицию как потенциальный центр
палиндрома и расширяемся в обе стороны, пока символы совпадают. Проверяем два
типа центров:

- на символе — для нечётных палиндромов ("aba")
- между символами — для чётных ("abba")

## Запуск

Импортируйте именованный export `findLongestPalindrome` из `solution.js` как ES
module.
