# Лабораторная работа 3

## Задание

Вариант 7. Реализуйте функцию difference(arr1, arr2), которая возвращает массив
элементов, которых нет во втором массиве

## Реализация

Для каждого элемента arr1 проверяем его наличие в arr2 линейным перебором. Если
элемент не найден — добавляем в результат.

## Запуск

Импортируйте именованный export `difference` из `solution.js` как ES module.
