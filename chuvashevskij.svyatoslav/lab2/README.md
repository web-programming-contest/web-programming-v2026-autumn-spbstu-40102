# Лабораторная работа 2

## Задание

Вариант 1. Реализовать функцию analyzeString, которая на вход принимает строку и
возвращает объект со следующей структурой: letters — количество букв digits —
количество цифр spaces — количество пробельных символов other — количество
остальных символов

## Реализация

Функция analyzeString принимает один аргумент - строку str, и возвращает объект
заданного вида. Алгоритм: Инициализировать счётчики letters, digits, spaces,
other нулями. Пройтись по каждому символу строки в цикле. Для каждого символа
определить его тип с помощью регулярных выражений. Инкрементировать
соответствующий счётчик. Вернуть объект с результатами.

Граничные случаи: Пустая строка "" - Все счётчики равны 0 Строка только из
пробелов - spaces = длина строки, остальные 0 Строка только из цифр - digits =
длина строки, остальные 0 Строка только из букв - letters = длина строки,
остальные 0 Строка со спецсимволами !@#$%^&*() - Все символы попадают в other
Смешанная строка - Корректный подсчёт каждой категории Строка с кириллицей -
Буквы а-я, А-Я, ё, Ё считаются как letters Аргумент не строка - Поведение не
определено (ожидается строка)

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
