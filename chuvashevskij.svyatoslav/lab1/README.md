# Лабораторная работа 1

## Задание

Вариант 1 Создать форму регистрации как на изображении. Форма должна
удовлетворять следующим требованиям:

- Ширина формы – 400px;
- Внутренний отступ – 8px;
- Цвет кнопки - #0056ff;
- Цвет кнопки при наведении курсора - #417ffb.

## Реализация

Заголовок с номером работу, затем форма регистрации. Были заданы классы для
формы и ее элементов, для каждого класса добавлены атрибуты по заданию.

## Запуск

Откройте `index.html` в браузере.
