# Лабораторная работа 3

## Задание

Задача 3. Реализовать функцию `removeDuplicates(arr)`, которая принимает массив
чисел и возвращает новый массив без дубликатов. Порядок первого появления чисел
сохраняется, исходный массив не изменяется.

Пример: `[1, 2, 2, 5, 6, 7, 5]` → `[1, 2, 5, 6, 7]`.

## Реализация

В файле `solution.js` находится именованный экспорт `removeDuplicates`. Функция
создаёт `Set` из входного массива: множество хранит уникальные значения в
порядке добавления. Затем оператор spread преобразует множество в новый массив.

Для пустого массива возвращается новый пустой массив. Если все числа одинаковые,
в результате остаётся одно число; если повторов нет, возвращается копия массива.
Поддерживаются отрицательные и дробные числа.

## Запуск

Из корня репозитория выполните команду в Node.js `24.19.0`:

```bash
node --input-type=module -e "import {removeDuplicates} from './chuvashevskij.svyatoslav/lab3/solution.js'; console.log(removeDuplicates([1, 2, 2, 5, 6, 7, 5]));"
```
