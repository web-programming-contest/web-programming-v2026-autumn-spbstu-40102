# Лабораторная работа 4

## Задание

Задача 4: библиотеки и книги.

Создать класс библиотеки с названием и массивом книг. Каждая книга содержит
название, автора, год издания и жанр. Реализовать добавление и удаление книг,
геттер количества книг и пять функций обработки коллекции библиотек.

Создать интерфейс с карточками книг, формами добавления книг и библиотек,
кнопками удаления. Добавление и удаление должны выполняться асинхронно через
`Promise` и `setTimeout`. Коллекция должна автоматически обновляться и
сохраняться в `localStorage` между посещениями.

## Реализация

В `model.js` именованно экспортируется класс `Library` (PascalCase согласно
контракту проверки). Конструктор `new Library(name, books = [])` создаёт
библиотеку с полями `name` и `books`, копируя переданный массив и объекты книг.

- `addBook(book)` добавляет копию книги.
- `removeBook(title)` удаляет все книги с указанным названием.
- Геттер `booksCount` возвращает текущее количество книг.

Также экспортируются функции, принимающие массив библиотек:

- `groupBooksByGenre(libraries)` — `Map`, где ключ — жанр, значение — массив
  книг.
- `getUniqueAuthors(libraries)` — массив уникальных авторов.
- `groupBooksByYear(libraries)` — `Map`, где ключ — числовой год, значение —
  массив книг.
- `getUniqueYears(libraries)` — массив уникальных годов издания.
- `findBooksByAuthor(libraries, author)` — все книги указанного автора, с точным
  сравнением имени.

Функции сохраняют порядок первого появления элементов и не изменяют входные
коллекции. Для пустой коллекции возвращаются пустые массивы или `Map`.

`index.html` содержит формы и список библиотек; `styles.css` задаёт адаптивное
оформление и видимый фокус клавиатуры. `main.js` отвечает за DOM и хранение
данных. Сначала нужно добавить библиотеку, затем выбрать её в форме книги.
Карточка книги показывает название, автора, год и жанр. Удаление библиотеки
удаляет и её книги. При совпадении названий книг в одной библиотеке удаляются
все совпадения.

Все четыре операции добавления и удаления проходят через `changeCollection`:
ожидается `Promise` с `setTimeout` на 300 мс, создаётся копия коллекции,
изменения сохраняются и отображаются без перезагрузки. Во время операции
элементы управления отключены. При ошибке сохранения текущая коллекция остаётся
прежней и выводится сообщение. Текст пользователя вставляется через
`textContent`.

Коллекция хранится под ключом `chuvashevskij.svyatoslav.lab4.libraries`. При
загрузке данные проверяются, экземпляры `Library` восстанавливаются из JSON.
Авторы и годы издания в обзоре автоматически пересчитываются при изменениях.

## Запуск

Из корня репозитория запустить локальный HTTP-сервер:

```bash
python3 -m http.server 8000
```

Открыть <http://localhost:8000/chuvashevskij.svyatoslav/lab4/>. HTTP-сервер
нужен для загрузки ES modules. Для проверки сохранения добавить библиотеку и
книгу, перезагрузить страницу, удалить книгу и снова перезагрузить страницу.

После установки корневых инструментов (`npm install`) выполнить из корня:

```bash
npm run format:check -- chuvashevskij.svyatoslav/lab4
npm run lint:js -- chuvashevskij.svyatoslav/lab4
npm run lint:css -- 'chuvashevskij.svyatoslav/lab4/**/*.css'
npm run lint:html -- 'chuvashevskij.svyatoslav/lab4/**/*.html'
```
