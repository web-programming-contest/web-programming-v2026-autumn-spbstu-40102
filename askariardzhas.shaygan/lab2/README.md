# Лабораторная работа 2

## Задание

Вариант 13. Написать функцию, которая по заданной дате определяет знак зодиака.

## Реализация

В файле `script.js` реализована функция `getZodiacSign(date)`.

- Принимает объект `Date` или строку, которую можно передать в конструктор
  `Date`.
- Проверяет корректность даты.
- По дню и месяцу возвращает название знака зодиака на русском языке.
- В конце файла приведены примеры вызовов функции.

## Запуск

Функцию можно проверить в Node.js интерактивно:

```
node
```

```js
const {getZodiacSign} = await import('./solution.js');

getZodiacSign('2000-03-25'); // Овен
getZodiacSign('1995-07-15'); // Рак
getZodiacSign(new Date(1990, 10, 5)); // Скорпион
```
