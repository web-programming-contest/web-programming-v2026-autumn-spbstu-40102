# Лабораторная работа 3

## Задание

Вариант 13. Написать функцию, которая сортирует массив по убыванию частоты
элементов.

## Реализация

В файле `solution.js` реализована функция `sortByFrequency(arr)`.

- Сначала подсчитывается количество вхождений каждого элемента.
- Затем массив сортируется по убыванию частоты.
- Исходный массив не изменяется.

## Запуск

Функцию можно проверить в Node.js:

```
node
```

```js
const {sortByFrequency} = await import('./solution.js');

sortByFrequency([4, 6, 2, 2, 6, 6, 4, 4, 4, 4]);
// [4, 4, 4, 4, 4, 6, 6, 6, 2, 2]
```
