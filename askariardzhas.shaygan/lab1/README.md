# Лабораторная работа 1

## Задание

Вариант 13. Создать блок с текстом любой длины. С помощью CSS реализовать
механизм, который скрывает текст, если он превышает высоту 100 пикселей или 3
строки. Если текст выходит за пределы указанного лимита, он должен обрезаться и
заменяться многоточием (…). Текст должен иметь шрифт Arial, размер шрифта —
16px.

## Реализация

В файле `index.html` создан блок с текстом (`div` с классом `text-block`).
Добавлены два примера: короткий текст (не обрезается) и длинный текст
(обрезается с многоточием).

В файле `styles.css` заданы:

- шрифт Arial, размер 16px;
- ограничение высоты (`max-height: 100px`);
- ограничение по количеству строк (`-webkit-line-clamp: 3`);
- обрезка текста с многоточием (`text-overflow: ellipsis` + `overflow: hidden`);
- дополнительные стили для наглядности (ширина, рамка, отступы).

## Запуск

Поскольку в работе используются только HTML и CSS (без JavaScript, модулей или
серверных запросов), **локальный сервер не нужен**.

Просто откройте файл `index.html` двойным кликом в любом браузере (Chrome,
Firefox, Edge и т.д.).
