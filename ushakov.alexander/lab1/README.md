# Лабораторная работа 1

## Задание

6 вариант. Создать меню блюд, используя неупорядоченный список. Меню должно
удовлетворять следующим требованиям:

- Каждый пункт меню (<li>) состоит из названия блюда и цены;
- Название блюда должно располагаться в левом краю контейнера, а цена должна
  прижиматься к правому краю, независимо от длины названия блюда (необходимо
  использовать Flexbox или Grid);
- Каждый пункт меню должен занимать всю ширину контейнера <ul>;
- Ширина контейнера <ul> - 400px;
- Между элементами списка должен быть вертикальный отступ 16px;
- Элементы списка должны быть разделены сплошной черной линией, толщина которой
  составляет 1px.

## Реализация

Страница состоит из `index.html` и подключённого файла `styles.css`. Меню -
неупорядоченный список `<ul>`, каждый пункт `<li>` содержит `<span>` с названием
и `<span>`с ценой. Раскладка пункта построена на Flexbox: название слева, цена
справа. Меню имеет ширину 400px, пункты растянуты на 100% его ширины, между ними
задан отступ 16px (`margin-bottom`) и разделительные линии 1px (`border-bottom`,
убираются у последнего пункта через `:last-child`).

## Запуск

Откройте `index.html` в браузере.
