# Лабораторная работа 5

## Задание

Задача 5. Реализовать механику рейтинга в книжном интернет-магазине. Создать
список книг с обложкой, названием, рейтингом, описанием и ценой. Пользователь
может выставить оценку от 1 до 5 звёзд. Рейтинг рассчитывается как среднее
значение всех оценок. После голосования 3,5 секунды отображается оценка
пользователя, затем — средний рейтинг.

## Реализация

Компонент App отрисовывает список книг. Каждая книга отображается компонентом
BookCard, а звёзды и вычисление рейтинга — компонентом Rating. useState хранит
оценки и временно выбранную оценку.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
