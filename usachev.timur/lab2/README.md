# Лабораторная работа 2

## Задание

Задача 2. Написать функцию convertBase(num, fromBase, toBase), преобразующую
число между системами счисления.

## Реализация

Функция переводит входное число в десятичную систему с помощью
`Number.parseInt`, а затем возвращает его в системе счисления `toBase` с помощью
`toString`.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
