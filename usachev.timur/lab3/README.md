# Лабораторная работа 3

## Задание

Задача 3. Реализуйте функцию mergeArrays(arr1, arr2), которая объединяет два
массива, удаляя дубликаты.

## Реализация

Функция сначала объединяет оба массива, а затем передаёт элементы в `Set`. `Set`
хранит только уникальные значения, а spread-оператор создаёт новый массив из
этих значений. Исходные массивы не изменяются.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
