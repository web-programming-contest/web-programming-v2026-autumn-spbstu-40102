# Лабораторная работа 4

## Задание

Вариант 4. Создать класс Order с номером заказа, списком товаров и статусом.
Реализовать добавление и удаление товаров, подсчёт суммы, функции обработки
массива заказов и интерфейс с асинхронным добавлением и удалением заказов и
товаров. Состояние должно сохраняться в localStorage.

## Реализация

Модель заказа находится в `model.js`. В нём описаны класс Order и функции
группировки, поиска и получения уникальных товаров. `main.js` отрисовывает
карточки заказов, обрабатывает действия пользователя и сохраняет актуальный
список заказов в localStorage.

## Запуск

Откройте `index.html` в браузере.
