# Лабораторная работа 2

## Задание

Вариант 5. Реализовать функцию `toBinary(num)`, которая преобразует десятичное
число в двоичную строку без ведущих нулей

## Реализация

Функция находится в `solution.js` и экспортируется по имени `toBinary`. Число
последовательно делится на два, а остатки образуют двоичную запись. Ноль
обрабатывается отдельно, некорректные значения приводят к ошибке

## Запуск

```bash
node --input-type=module -e "import('./solution.js').then(({toBinary}) => console.log(toBinary(5)))"
```
