# Лабораторная работа 5

## Задание

Вариант 5. Создать книжный каталог в виде дерева из четырёх уровней: автор,
издательство, жанр и название книги. Добавить возможность раскрывать и
сворачивать ветки

## Реализация

Каталог реализован на React. Компонент `TreeNode` рекурсивно выводит ветки, а
состояние хранит список раскрытых элементов. Кнопки «Раскрыть все» и «Свернуть
все» управляют всем деревом сразу

## Как запустить

```bash
npm install
npm run dev
```

Vite выведет в терминал адрес страницы. Обычно это `http://localhost:5173`

Проверить production-сборку можно командой `npm run build`
