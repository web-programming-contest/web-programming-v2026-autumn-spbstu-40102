# Лабораторная работа 4

## Задание

Вариант 5. Создать класс команды и функции для работы со списком команд и
участников. Сделать интерфейс для добавления и удаления команд и участников,
выполнять операции асинхронно и сохранять данные в `localStorage`

## Реализация

В `model.js` находятся класс `Team` и пять функций для обработки коллекции. В
`main.js` реализованы карточки, формы и обновление интерфейса. Добавление и
удаление выполняются через `Promise` и `setTimeout`, а текущее состояние
сохраняется между перезагрузками страницы

## Запуск

Перейдите в папку лабораторной и запустите локальный сервер

```bash
python3 -m http.server 8004
```

После запуска откройте `http://localhost:8004`
