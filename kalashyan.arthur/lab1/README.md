# Лабораторная работа 1

## Задание

Вариант 5. Создать постраничную навигацию, расположить её по центру и выровнять
текст внутри элементов по двум осям. Выделить активную страницу и менять фон
элементов при наведении

## Реализация

Навигация состоит из трёх номеров страниц и двух стрелок. Flexbox отвечает за
центрирование, CSS выделяет активную и наведённую кнопки, а JavaScript меняет
страницу и обновляет текст без перезагрузки

## Запуск

Открыть `index.html`
