# Лабораторная работа 3

## Задание

Вариант 5. Реализовать функцию `chunkArray(arr, size)`, которая разбивает массив
на подмассивы указанного размера

## Реализация

Функция находится в `solution.js` и экспортируется по имени `chunkArray`. Метод
`slice` создаёт отдельные части и не изменяет исходный массив. Если в конце
остаётся меньше элементов, они попадают в последний подмассив

## Запуск

Перейдите в папку лабораторной и выполните команду

```bash
node --input-type=module -e "import('./solution.js').then(({chunkArray}) => console.log(chunkArray([1,2,3,4,5], 2)))"
```
