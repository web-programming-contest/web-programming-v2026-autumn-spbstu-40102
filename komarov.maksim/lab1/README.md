# Лабораторная работа 1

## Задание

Вариант 2. Создать навигационный компонент «хлебные крошки» по образцу из
методички.

Требования:

- использовать список как основу разметки;
- оформить промежуточные пункты списка ссылками;
- последний пункт сделать элементом `span`;
- установить цвет ссылок `#0056ff`, а последнего пункта — `#333`;
- подчеркивать ссылки при наведении курсора;
- добавить разделители между пунктами через CSS-псевдоэлемент `::after`.

## Реализация

В файле `index.html` компонент размещён внутри семантического элемента `nav` с
указанием его назначения через `aria-label`. Структура навигации — список `ul` с
тремя элементами `li`: «Главная», «Каталог», «Техника». Первые два пункта
содержат ссылки `a`, а последний — элемент `span` с атрибутом
`aria-current="page"`.

В файле `styles.css` заданы цвета, отображение пунктов в строку и подчеркивание
ссылок при наведении или фокусе. Разделители `>` добавляются правилом
`.breadcrumbs-item:not(:last-child)::after`; дополнительный HTML для стрелок не
используется. Для небольших экранов предусмотрены перенос элементов списка и
уменьшение отступов.

## Запуск

Откройте файл `index.html` в браузере или воспользуйтесь встроенным
предпросмотром GoLand. Сборка и установка зависимостей не требуются. Проверьте
подчеркивание ссылок при наведении курсора и отсутствие разделителя после
последнего пункта.
