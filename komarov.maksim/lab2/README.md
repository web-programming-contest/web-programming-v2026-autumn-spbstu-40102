# Лабораторная работа 2

## Задание

Вариант 2. Написать функцию `toRoman(num)`, преобразующую целое число от 1 до
3999 в римскую запись.

Примеры: `toRoman(4)` → `"IV"`, `toRoman(58)` → `"LVIII"`, `toRoman(1994)` →
`"MCMXCIV"`.

## Реализация

В `solution.js` реализована функция `toRoman` с именованным экспортом ES-модуля.

Используются два массива одинаковой длины: `numbers` содержит арабские значения
по убыванию, а `letters` — соответствующие римские обозначения. Цикл `for`
перебирает номиналы. Пока остаток не меньше текущего номинала, цикл `while`
добавляет его римское обозначение в результат и вычитает номинал из остатка.

В таблицах учтены вычитательные записи `IV`, `IX`, `XL`, `XC`, `CD` и `CM`. Для
нецелого числа или значения вне диапазона 1–3999 выбрасывается `RangeError`.

## Запуск

Из корня репозитория выполните:

```bash
node --input-type=module -e 'import { toRoman } from "./komarov.maksim/lab2/solution.js"; console.log(toRoman(1994));'
```

Ожидаемый вывод: `MCMXCIV`. Дополнительные библиотеки не нужны.
