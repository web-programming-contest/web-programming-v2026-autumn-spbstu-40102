# Лабораторная работа 3

## Задание

Вариант 2. Реализовать функцию `rotateArray(arr, steps)`, которая циклически
сдвигает массив вправо на `steps` элементов.

Пример: `rotateArray([1, 2, 3, 4, 5], 2)` возвращает `[4, 5, 1, 2, 3]`.

## Реализация

В файле `solution.js` находится функция `rotateArray` с именованным экспортом
ES-модуля.

Сначала функция проверяет пустой массив, чтобы не выполнять деление по модулю
нуля. Затем вычисляет эффективный сдвиг с помощью оператора `%`. Цикл `for`
перебирает исходные элементы и помещает каждый в новую позицию
`(i + shift) % length`.

Функция возвращает новый массив, не изменяя исходный. Сдвиг, превышающий длину
массива, обрабатывается корректно. Отрицательное целое число шагов эквивалентно
сдвигу влево.

## Запуск

Из корня репозитория вызовите:

```bash
node --input-type=module -e 'import { rotateArray } from "./komarov.maksim/lab3/solution.js"; console.log(rotateArray([1, 2, 3, 4, 5], 2));'
```

Ожидаемый вывод: `[ 4, 5, 1, 2, 3 ]`. Сторонние библиотеки не требуются.
