# REST API

Локальный адрес: `http://127.0.0.1:8080`. Все маршруты имеют префикс `/api`.
Ответы — JSON, кроме стандартных ответов 404/405 от ServeMux. Ошибка прикладного
запроса: `{"error":"Сообщение"}`.

| Метод | Маршрут        | Доступ      | Назначение                                 |
| ----- | -------------- | ----------- | ------------------------------------------ |
| GET   | `/api/health`  | Всем        | Проверка работы сервера                    |
| GET   | `/api/goods`   | Всем        | Товары для главной и каталога              |
| GET   | `/api/session` | Всем        | Текущее состояние входа                    |
| POST  | `/api/login`   | Всем        | Вход, установка cookie                     |
| POST  | `/api/logout`  | Всем        | Отзыв сессии и удаление cookie             |
| GET   | `/api/orders`  | После входа | Заказы текущего пользователя, новые сверху |
| POST  | `/api/orders`  | После входа | Проверка и создание заказа                 |

Во всех POST-запросах нужны `Content-Type: application/json` и
`X-Gadget-Request: true`. Cookie следует передавать в последующих запросах. Во
фронтенде установлен `credentials: 'include'`. Тела больше 64 KiB и неизвестные
поля отклоняются. Браузерные cross-origin запросы разрешены только для origin из
конфигурации.

## Вход

```bash
curl -i -c /tmp/gadget-cookies.txt \
  -H 'Content-Type: application/json' \
  -H 'X-Gadget-Request: true' \
  -d '{"username":"student","password":"gadget123"}' \
  http://127.0.0.1:8080/api/login
```

Успех: HTTP 200, `{"authenticated":true,"user":"student"}` и HttpOnly cookie.
Неправильные данные: HTTP 401. Сессия живёт восемь часов и сбрасывается при
перезапуске сервера.

## Создание заказа

```bash
curl -b /tmp/gadget-cookies.txt \
  -H 'Content-Type: application/json' \
  -H 'X-Gadget-Request: true' \
  -d '{"items":[{"productId":102,"quantity":1},{"productId":103,"quantity":2}],"phone":"+7 (900) 000-00-00","email":"","delivery":"pickup","address":"","payment":"card","wrapping":false}' \
  http://127.0.0.1:8080/api/orders
```

Пример создаёт три единицы товаров на 31 990 ₽. Пример телефона — фиктивное
значение для демонстрации; звонки и сообщения приложение не отправляет.

| Поле       | Значение                                                                  |
| ---------- | ------------------------------------------------------------------------- |
| `items`    | От 1 до 100 уникальных позиций, `productId` и целое `quantity` от 1 до 99 |
| `phone`    | Обязательный номер с 10–15 цифрами; допускаются пробелы, `+`, `-`, скобки |
| `email`    | Необязательный email, пустая строка допустима                             |
| `delivery` | `pickup` или `delivery`                                                   |
| `address`  | Обязателен при `delivery`, до 500 символов; при самовывозе очищается      |
| `payment`  | `card` или `cash`                                                         |
| `wrapping` | `true` или `false`                                                        |

Успех — HTTP 201 с созданным заказом. `id`, `createdAt`, `user`, `quantity`,
`total` и цены позиций вычисляет сервер. Денежные значения — целое количество
рублей. Клиент не может передать собственную цену или итог. Создание завершается
успехом только после записи на диск.

Ошибки: 400 — некорректные данные; 401 — нет сессии; 403 — запрещённый
origin/нет служебного заголовка; 415 — неверный Content-Type; 500 — ошибка
сохранения. При ошибке оформления фронтенд не очищает корзину.

## История и выход

```bash
curl -b /tmp/gadget-cookies.txt http://127.0.0.1:8080/api/orders
curl -b /tmp/gadget-cookies.txt -H 'Content-Type: application/json' \
  -H 'X-Gadget-Request: true' -d '{}' http://127.0.0.1:8080/api/logout
```

При прямом вызове этих примеров создаётся настоящий учебный заказ в локальном
`orders.json`; браузерная корзина при этом не изменяется.
