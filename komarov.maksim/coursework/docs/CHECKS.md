# Проверки и решения по ТЗ

## Автоматические проверки

Проверены production-сборка Vite, пять тестов клиентской логики, Go-тесты с
детектором гонок и `go vet`. Покрытие пакета `internal/shop` — около 81%
инструкций; точное значение выводит `go test -cover ./...`.

Go-тесты проверяют:

- вход, отказ при неверном пароле, защиту истории и отзыв сессии;
- свойства HttpOnly cookie и запрет чужого origin;
- отказ при попытке передать клиентскую итоговую цену;
- валидацию корзины, телефона, email, получения и оплаты;
- расчёт количества и суммы по серверным данным;
- восстановление истории и продолжение нумерации после повторного открытия
  хранилища;
- изоляцию заказов по пользователю;
- отсутствие потерянных заказов при 20 одновременных записях;
- отсутствие изменения истории и счётчика ID при ошибке записи файла.

Клиентские тесты проверяют сочетание фильтров, числовую сортировку, неизменность
исходного массива, повреждённое содержимое localStorage, обязательность адреса и
необязательность email, русские окончания количества.

## Проверка через браузер

Проверены главная и страница входа, переход гостя из каталога на вход, пустой и
неверный вход, успешный вход, карточка и Esc, добавление и изменение количества,
фильтр категории, пустая выдача и сброс, пагинация, сохранение корзины после
обновления, заполненная корзина, подтверждение и отмена удаления, выборочное
удаление, ошибки формы, обязательный адрес доставки, оформление и запись заказа
в истории.

Тестовый заказ: робот × 1 и часы Geozon Pink × 2; сумма 31 990 ₽. Состав и итог
проверены в интерфейсе и серверном файле. Файл с заказом пережил перезапуск
сервера. В выдаваемом архиве история очищена.

## Принятые решения

| Вопрос                                            | Решение                                                                                                       |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Email в PDF помечен звёздочкой, в ТЗ необязателен | Следуем тексту ТЗ: email необязателен                                                                         |
| На иллюстрации успешного заказа товары ещё видны  | После успешной записи очищаем корзину, как требует ТЗ                                                         |
| Чекбоксы в корзине                                | Выбирают позиции для удаления; оформление включает всю текущую корзину                                        |
| Число в шапке                                     | Сумма количеств: одна позиция × 2 и другая × 1 дают 3                                                         |
| Цена                                              | Два поля «От» и «До», базовый вариант прямо разрешён ТЗ                                                       |
| Нет отмеченных типов или цветов                   | Все варианты по этому признаку                                                                                |
| Популярность                                      | Демонстрационное поле `popularity`; рейтинг отображается отдельно                                             |
| Новизна                                           | Метка `isNew` и дата `releaseDate`; новинки идут первыми                                                      |
| Количество одной позиции                          | От 1 до 99; уменьшение до 0 удаляет позицию                                                                   |
| Регистрация и оплата                              | Регистрации нет; выбор оплаты сохраняется в заказе без платёжной интеграции                                   |
| Исходные ресурсы неполные                         | Каталог дополнен, отсутствующие изображения извлечены из .fig; баннер и декорации входа экспортированы из PDF |
| Ширина                                            | Десктопная версия, мобильная адаптация не требуется                                                           |

Дизайн воспроизведён по PDF и выданному UI kit. Баннер и декорации входа
экспортированы как растровые ресурсы; отдельные пиктограммы заменены
соответствующими иконками lucide-react. Поэтому абсолютное совпадение всех
векторных значков с Figma не заявляется.
