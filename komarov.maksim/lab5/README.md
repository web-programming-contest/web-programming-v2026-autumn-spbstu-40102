# Лабораторная работа 5

## Задание

Вариант 2. Реализовать компонент пагинации для книжного интернет-магазина.
Отобразить список книг с обложкой, названием, рейтингом, описанием и ценой. Под
списком разместить кнопки перехода назад, вперёд и по номерам страниц. На одной
странице должно находиться девять книг, расположенных по три в строке. Учесть
возможность наличия двадцати страниц.

## Реализация

Приложение написано на React с использованием функциональных компонентов и хука
`useState`. Сборка выполняется через Vite.

- `src/main.jsx` — главный компонент `App`, хранение текущей страницы и
  отображение книг.
- `src/components/BookCard.jsx` — карточка книги с обложкой, рейтингом,
  описанием и ценой.
- `src/components/Pagination.jsx` — кнопки перехода по страницам и управление
  доступностью кнопок.
- `src/data/books.js` — локальный тестовый каталог из 180 книг и функции выбора
  элементов для страницы.
- `src/styles.css` — оформление карточек, сетка из трёх столбцов, адаптация к
  узким экранам.
- `assets/` — локальные SVG-обложки, которые работают без подключения к
  интернету.

Данные учебные и вымышленные. Пагинация показывает девять книг на странице и
поддерживает двадцать страниц. Переход между страницами не перезагружает
документ. Кнопки «Назад» и «Вперёд» блокируются на границах списка.

## Запуск

Требуется Node.js и npm. В терминале, находясь в каталоге `komarov.maksim/lab5`,
выполните:

```bash
npm install
npm run dev
```

Откройте адрес, указанный Vite (обычно `http://localhost:5173/`). Чтобы
проверить сборку, выполните `npm run build`.
