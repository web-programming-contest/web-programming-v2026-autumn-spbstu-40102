# Лабораторная работа 4

## Задание

Вариант 2. Создать класс `Student` с полями `id`, `name` и `grades`, методами
`addGrade(subject, grade)`, `getAverageGrade()` и геттером `summary`.
Реализовать группировку студентов по среднему баллу и предметам, список
уникальных предметов, поиск студентов с максимальным средним баллом и студентов,
сдавших указанный предмет.

Создать страницу со списком студентов, добавлением и удалением студентов и
оценок, асинхронными операциями через `Promise` и `setTimeout`, обновлением
интерфейса без перезагрузки и сохранением данных в `localStorage`.

## Реализация

- `model.js` — класс `Student` и функции обработки массива студентов.
  Группировки возвращаются как `Map`, уникальные предметы собираются через
  `Set`. При отсутствии оценок средний балл равен нулю. Сдавшим предмет
  считается студент с оценкой не ниже 3.
- `main.js` — создание карточек через DOM API, обработчики форм и кнопок,
  асинхронные операции добавления и удаления, перерисовка списка и сохранение в
  `localStorage`.
- `index.html` — структура страницы, форма добавления студента и контейнер для
  карточек.
- `styles.css` — стили страницы и адаптация под разные размеры экрана.

Добавление оценки по уже существующему предмету обновляет её. Удаление оценки
выполняется кнопкой рядом с предметом. У студента должен быть уникальный
числовой ID.

## Запуск

Из каталога `komarov.maksim/lab4` запустить локальный HTTP-сервер:

```bash
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000` в браузере. Также можно воспользоваться
встроенным HTTP-сервером GoLand.

Для проверок из корня репозитория курса:

```bash
npm run format -- komarov.maksim/lab4
npm run format:check -- komarov.maksim/lab4
npm run lint:js -- komarov.maksim/lab4
npm run lint:css -- "komarov.maksim/lab4/**/*.css"
npm run lint:html -- "komarov.maksim/lab4/**/*.html"
```
