# Лабораторная работа 5

## Задание

Создать список книг в книжном магазине. В правом верхнем углу расположить кнопку
переключения темы. Реализовать переключение светлого и тёмного режимов с помощью
Context API. Кнопка меняет название и иконку в зависимости от выбранного режима,
для каждого цвета светлой темы подобран альтернативный цвет тёмной темы.
Дизайн-библиотеки не используются.

## Реализация

- React и Vite.
- `src/ThemeContext.js` — контекст темы и хук `useTheme`.
- `src/App.jsx` — хранит текущую тему в состоянии и передаёт её с функцией
  переключения через `ThemeContext.Provider`.
- `src/components/ThemeToggle.jsx` — кнопка переключения темы, читает контекст.
- `src/components/BookList.jsx` — список книг из `src/books.js`.
- `src/styles.css` — цвета заданы CSS-переменными: для светлой темы они
  определены в `.app`, для тёмной переопределяются в `.app[data-theme="dark"]`.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`.
