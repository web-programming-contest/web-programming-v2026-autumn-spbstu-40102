# Лабораторная работа 1

## Задание

Вариант 23. Создать регистрационную форму со следующими полями ввода: имя,
фамилия, email, пароль, подтверждение пароля (текстовые поля), дата рождения
(поле выбора даты), пол (радиокнопки с вариантом для выбора) и кнопка отправки.
В полях ввода необходимо корректно использовать атрибут `type`. Отступы между
полями — 10px, цвет фона формы — `#f2f2f2`, цвет текста — `#333`.

## Реализация

Страница состоит из формы `form.reg-form`, внутри которой каждое поле обёрнуто в
блок `.form-group` вместе со своим `label`, фон и цвет текста формы —
`background-color: #f2f2f2` и `color: #333` у класса `.reg-form`.

## Запуск

Откройте `index.html` в браузере.
