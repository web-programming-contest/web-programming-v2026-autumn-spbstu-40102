# Лабораторная работа 4

## Задание

Создать класс `Game` (поля `title`, `platforms`, `releaseYear`; методы
`addPlatform`, `removePlatform`, геттер `platformCount`), реализовать функции
работы с массивом игр (группировка по году выпуска, список уникальных платформ,
игры на заданной платформе, группировка по количеству платформ, игры после
заданного года) и создать пользовательский интерфейс: карточки игр, добавление и
удаление игр и платформ, форма создания игры. Операции выполняются асинхронно
через `Promise` и `setTimeout`, список сохраняется в `localStorage`.

## Реализация

- `model.js` — класс `Game` и функции `groupGamesByReleaseYear`,
  `getUniquePlatforms`, `findGamesByPlatform`, `groupGamesByPlatformCount`,
  `findGamesReleasedAfter`. Входные массивы не изменяются.
- `main.js` — интерфейс: отрисовка карточек, обработчики формы и кнопок,
  асинхронные операции добавления и удаления (`Promise` + `setTimeout`),
  сохранение и восстановление списка из `localStorage`.
- `index.html`, `styles.css` — разметка и стили.

## Запуск

Открыть `index.html` через локальный сервер
