# Лабораторная работа 3

## Задание

Вариант 23. Реализовать функцию `findLongestIncreasingSubsequence(arr)`, которая
находит длину наибольшей возрастающей подпоследовательности.

## Реализация

Функция `findLongestIncreasingSubsequence` экспортируется из `solution.js` как
именованный ES module export. Решение использует динамическое программирование:
`lengths[i]` хранит длину наибольшей возрастающей подпоследовательности,
заканчивающейся на элементе `i`, а ответ — максимум по всем `i`. Для пустого
массива возвращается `0`, исходный массив не изменяется.

## Запуск

Импортируйте именованный export `findLongestIncreasingSubsequence` из файла
`solution.js` как ES module.
