# Лабораторная работа 1

## Задание

Свёрстать флаг Японии. Красный круг в центре размещён с помощью
`position: absolute` так, чтобы оставаться по центру при изменении размеров
флага.

## Реализация

Флаг — блок `.flag` с `position: relative`. Круг `.flag__circle` —
`position: absolute`, центрируется через `top: 50%; left: 50%;` и
`transform: translate(-50%, -50%)`. Сама страница центрирует флаг с помощью
flexbox на `body`.

## Запуск

Открыть `index.html` в браузере — сервер не требуется.
