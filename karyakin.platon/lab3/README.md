# Лабораторная работа 3

## Задание

Вариант 32. Реализовать функцию `difference(arr1, arr2)`, которая возвращает
массив элементов, которых нет во втором массиве.

## Реализация

Функция `difference` экспортируется из `solution.js` как именованный ES module
export.

Элементы `arr2` добавляются в `Set` для быстрого поиска, после чего `arr1`
фильтруется: остаются только элементы, отсутствующие в этом сете.

## Запуск

Импортируйте именованный export `difference` из файла `solution.js` как ES
module.
