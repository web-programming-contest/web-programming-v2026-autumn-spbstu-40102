# Лабораторная работа 2

## Задание

Написать функцию `findLongestPalindrome(str)`, которая находит и возвращает
самую длинную подстроку-палиндром в переданной строке.

## Реализация

Используется метод "расширение от центра": для каждой позиции строки проверяются
два варианта центра палиндрома — один символ (нечётная длина) и промежуток между
символами (чётная длина). Указатели `left` и `right` расширяются, пока символы
совпадают. Запоминается самый длинный найденный палиндром.

## Запуск

```bash
node -e "import('./solution.js').then(m => console.log(m.findLongestPalindrome('babad')))"
```
