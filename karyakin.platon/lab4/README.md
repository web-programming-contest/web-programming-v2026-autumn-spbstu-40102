# Лабораторная работа 4

## Задание

Вариант 32. Создать класс `Event` с полями `id`, `title`, `participants` и
`date` и методами `addParticipant(name)`, `removeParticipant(name)` и геттером
`participantCount`. Реализовать функции для массива мероприятий: группировка по
дате, уникальный список участников, группировка по количеству участников, поиск
мероприятий заданного участника и мероприятий заданного месяца.

Реализовать интерфейс: карточки мероприятий (название, дата, участники,
количество участников), кнопки «Добавить участника», «Удалить участника»,
«Добавить мероприятие», «Удалить мероприятие», формы создания мероприятия и
добавления участника. Интерфейс обновляется автоматически, все операции
выполняются асинхронно через `Promise` и `setTimeout`, список мероприятий
сохраняется в `localStorage`.

## Реализация

Модель находится в `model.js`: класс `Event` и функции `groupEventsByDate`,
`getUniqueParticipants`, `groupEventsByParticipantCount`,
`findEventsByParticipant`, `findEventsByMonth`. Дата хранится строкой в формате
`ГГГГ-ММ-ДД`, номер месяца берётся из неё напрямую, без часовых поясов. Функции
не изменяют переданный массив.

Интерфейс находится в `main.js`. Состояние хранится в массиве экземпляров
`Event` и записывается в `localStorage` под ключом `events`. Каждое изменение
проходит через `runAsync`, которая оборачивает действие в `Promise` с
`setTimeout`, после чего список карточек перерисовывается.

сервер, например:

```bash
cd karyakin.platon/lab4

```

После запуска откройте адрес, который выведет команда.
