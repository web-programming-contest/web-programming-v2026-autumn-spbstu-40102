# Лабораторная работа 2

## Задание

Вариант 37.

Реализовать функцию `formatPhoneNumber(number)`, которая принимает строку из 10
цифр и возвращает номер телефона в формате `+7 (XXX) XXX-XX-XX`.

Пример:

Вход: `"9991234567"`

Результат: `"+7 (999) 123-45-67"`

## Реализация

Функция `formatPhoneNumber` реализована в файле `solution.js` и экспортируется с
помощью именованного экспорта.

Для форматирования используется метод `slice()`, который разделяет исходную
строку на четыре части: 3, 3, 2 и 2 цифры.

Полученные части объединяются в одну строку с помощью шаблонной строки
JavaScript.

Функция рассчитана на входную строку из 10 цифр. Дополнительная проверка
некорректных данных не реализована.

## Запуск

Для проверки необходимо импортировать именованный экспорт `formatPhoneNumber` из
файла `solution.js` как ES module.

Пример использования:

```js
import {formatPhoneNumber} from './solution.js';

console.log(formatPhoneNumber('9991234567'));
```

Ожидаемый результат:

```text
+7 (999) 123-45-67
```
