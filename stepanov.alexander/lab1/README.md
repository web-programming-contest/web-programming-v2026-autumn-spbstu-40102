# Лабораторная работа 1

## Задание

Вариант 37.

Создать три частично перекрывающихся прямоугольника: красный слева, зелёный по
центру и синий справа. Красный должен находиться под зелёным, а синий — поверх
зелёного.

## Реализация

Страница состоит из трёх элементов `div` с классами `red`, `green` и `blue`.

В файле `styles.css` заданы размеры и цвета прямоугольников. Для их расположения
используется `position: absolute` и свойства `left` и `top`. Порядок перекрытия
определяется свойством `z-index`.

## Запуск

Открыть файл `index.html` в браузере.
