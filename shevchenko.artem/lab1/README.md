# Лабораторная работа 1

## Задание

Вариант №29
Создать список задач, где каждый элемент списка имеет разную иконку, вместо классических маркеров, в зависимости от статуса задачи

## Реализация

В файле `index.html` создана базовая структура страницы с заголовком и маркированным списком из трёх задач. Каждому элементу списка присвоен класс, соответствующий статусу задачи: `completed` (выполнена), `aborted` (отменена), `process` (в процессе).

В файле `styles.css` стандартные маркеры списка убраны с помощью `list-style-type: none`. Вместо них к каждому элементу списка добавлен псевдоэлемент `::before`, в свойство `content` которого подставляется нужный Unicode-символ в зависимости от класса элемента.

## Запуск

Откройте `index.html` в браузере.
