# Лабораторная работа 5

## Задание

Вариант 29. TODO-список на React.

Приложение должно позволять:

- добавлять новую задачу;
- отмечать задачу выполненной;
- удалять задачу;
- фильтровать задачи: все, активные, выполненные.

По условию нужно использовать функциональные компоненты и хуки состояния.

## Реализация

Приложение находится в `src/main.tsx`, стили — в `src/styles.css`.

Состояние хранится в компоненте `App` через `useState`: массив задач `todos` и
текущий фильтр `filter`. Отдельные компоненты:

- `TodoForm` — поле ввода и кнопка добавления;
- `TodoItem` — одна задача с чекбоксом и кнопкой удаления.

Список задач сохраняется в `localStorage` в `useEffect`, а при запуске
восстанавливается функцией `loadTodos`. Фильтрация выполняется обычным `filter`
по полю `done`.

Публичные селекторы для проверки: `todo-input`, `todo-add`, `todo-filter`,
`todo-list`, `todo-item`.

## Запуск

```bash
cd lab5
npm install
npm run dev
```

Для сборки используется команда `npm run build`.
