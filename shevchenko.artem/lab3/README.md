# Лабораторная работа 3

## Задание

Вариант 29. Реализуйте функцию mergeArrays(arr1, arr2), которая объединяет два
массива, удаляя дубликаты.

## Реализация

Алгоритм состоит из двух частей:

1. Сортировка массивов
2. Совмещение с удалением дубликатов

Совмещение с удалением дубликатов реализовано при помощи последовательного
перемещения двух указателей по двум массивам и сравнением элементов под ними.
Так как массивы отсортированы, дубликаты всегда будут находится рядом.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
