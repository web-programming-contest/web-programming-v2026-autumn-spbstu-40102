# Лабораторная работа 2

## Задание

Вариант 29. Написать функцию `convertBase(num, fromBase, toBase)`, преобразующую
число между системами счисления (из `fromBase` в `toBase`).

## Реализация

Алгоритм состоит из двух частей:

1. Перевод из системы `fromBase` в десятичную
2. Перевод из десятичной системы в систему `toBase`

Распознавание символов построено на базе сравнения их `Unicode` кодов, при
помощи чего символами (`A`, `B`,... `Z`) можно оперировать как цифрами для
перевода из одной системы счисления в другую.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
