# Лабораторная работа 4

## Задание

Вариант 29. Нужно сделать список заказов и товаров.

В модели должен быть класс `Order` с номером заказа, списком товаров и статусом.
У класса есть методы `addItem`, `removeItem` и `getTotal`.

Также нужны функции для работы с массивом заказов:

- `groupOrdersByStatus` - группирует заказы по статусу;
- `getUniqueItems` - возвращает все товары без повторов;
- `groupOrdersByTotal` - группирует заказы по сумме;
- `findOrdersByItem` - ищет заказы с нужным товаром;
- `findOrdersByStatus` - ищет заказы с нужным статусом.

В интерфейсе можно добавить и удалить заказ, добавить и удалить товар, а также
поменять статус заказа. Все изменения сохраняются в `localStorage`.

## Реализация

Модель лежит в `model.ts`, интерфейс - в `main.ts`, стили - в `styles.css`.

Заказы хранятся в массиве `orders`. При добавлении или удалении сначала
создаётся `Promise` с `setTimeout`, а после него обновляются массив, страница и
`localStorage`. Список заказов перерисовывается функцией `render`.

Статус заказа меняется через выпадающий список. Номер заказа в карточке показан
как текст, поэтому изменить его нельзя.

## Запуск

В CI точка входа `main.ts` автоматически собирается в JavaScript. Браузер сам
TypeScript не запускает, поэтому для локального просмотра удобно использовать
Vite:

```bash
npx vite lab4
```

Vite запустит локальный сервер и сам соберёт TypeScript-файлы. После этого
откройте адрес, который он покажет в терминале.
